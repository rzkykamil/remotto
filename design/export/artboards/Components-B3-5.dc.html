Prototype yang tersedia
SCR-010 Remote (4 ukuran/tema) · berfungsi: play/pause, slider, mute, −/+. Simulasi: status lewat tweak.
Prototype daya · berfungsi: sheet, tahan 1,2 dtk, hitung mundur, batal. Simulasi: agent selalu sukses.
Prototype pairing · berfungsi: intro → izin → scan → tes → berhasil → link ke Remote; isi manual dengan validasi alamat. Simulasi: tombol DEMO untuk QR; 10.0.0.1 = timeout, token 000000 = ditolak.
Hanya anotasi: dialog izin OS, kamera asli, haptic, screen reader, transisi antar layar.
Isu terbuka & penyimpangan
Penyimpangan D1: error validasi form pakai oranye (accent.text) + ikon, bukan merah — konsisten dengan prinsip "merah cuma untuk bahaya".
Terbuka: port default agent 8765 — angka ini asumsi, harus disamakan dengan agent Go.
Terbuka: format QR (mis. remotto://192.168.1.20:8765?t=K7QF2M) ditentukan saat scaffold; desain cuma butuh: alamat, token, nama laptop.
Belum diverifikasi: kontras teks di atas viewfinder kamera asli, keterbacaan token mono di 360 dp, perilaku izin kamera iOS vs Android.

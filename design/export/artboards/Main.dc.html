REMOTTO · GATE D1 · DRAFT

Remote pribadi buat laptop Windows, dipakai sambil rebahan.

Satu pengguna, satu laptop, WiFi yang sama. HP kirim perintah ke agent kecil di laptop. Sukses = media dan volume bisa satu tangan, satu ketukan, tanpa baca; shutdown mustahil kepencet; status online/offline selalu jelas.

Navigasi

Pairing (first-run) → berhasil → Remote (home) ⇄ push ⇄ Pengaturan
Di atas Remote: bottom sheet Sleep, sheet Restart / Matikan (tahap 1 → tahap 2), layar Hitung mundur (full-screen, modal). Snackbar untuk gagal kirim / dibatalkan.
Token ditolak (401) dari mana pun → balik ke Pairing dengan pesan. Back sistem di Remote = keluar app; di sheet = tutup sheet; di hitung mundur = Batal.

Flow utama + pemulihan

(a) Pairing pertama. Buka app → minta izin kamera → scan QR dari agent → tes koneksi ("Lagi nyambung…") → simpan → Remote. Pulih: izin ditolak → tombol "Buka pengaturan" + "Isi manual"; QR bukan Remotto → "QR-nya bukan dari Remotto"; timeout → "Coba lagi"; token ditolak → scan ulang.
(b) Harian. Buka → status pill "Nyambung" → tap play/pause, geser volume, tap mute. Tombol beri respons instan (pressed + haptic), angka volume update saat ditarik. Pulih: perintah gagal → snackbar "Gagal kirim" + "Ulangi"; slider gagal → nilai balik ke nilai laptop.
(c) Shutdown / Restart. Tap "Matikan" atau "Restart" (atas, kecil) → sheet tahap 1 "Yakin matiin?" → tahap 2 tahan tombol 1,2 dtk → hitung mundur 5 dtk dengan "Batal" besar → terkirim. Pulih: Batal kapan pun dalam 5 dtk → "Nggak jadi dimatiin".
(d) Offline → online. 2 polling gagal → pill "Nggak kejangkau", semua kontrol nonaktif, panel "Coba lagi" + "Pairing ulang". Polling jalan terus; begitu balik → pill "Nyambung lagi" 2 dtk → normal.

Keputusan terbuka

Q1Tahap 2 shutdown: tahan 1,2 dtk (usulan) atau tap kedua? Tahan lebih aman di kasur, tapi butuh alternatif buat screen reader (double-tap lalu tahan ala TalkBack / aksi Semantics).
Q2Delay 5 dtk dipegang agent (app kirim "jadwalkan", bisa "batal") atau app (baru kirim setelah 5 dtk)? Asumsi: agent, supaya batal tetap jalan walau app ditutup. Butuh endpoint cancel.
Q3Ambang offline: asumsi 2 polling gagal (±10 dtk) biar pill nggak kedip-kedip. Di antaranya state "Menyambung…".

Asumsi (bisa direvisi)

Penyimpangan dari brief (disetujui): arah visual jadi Liquid Glass (brief awal: hindari glassmorphism); Restart masuk scope Konfirmasi daya, perlakuannya sama dengan shutdown. · Haptic default on · Uptime tampil kecil di pill status · Volume step −/+ = 5% · Sleep juga lewat hitung mundur 5 dtk (sesuai aturan bisnis), tapi cuma 1 konfirmasi · Kontrol media "fire and forget": nggak ada now-playing, jadi ikon play/pause = toggle, bukan status asli laptop.

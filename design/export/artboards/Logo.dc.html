Remotto
LOCKUP · MARK + WORDMARK GEIST BOLD −3%
Pakai
Ikon gelap = ikon launcher default (paling cocok dengan pemakaian malam). Mark (kapsul garis + bola) untuk splash, layar intro pairing, dan header. Bola selalu oranye, garis ikut warna teks.
Jangan
Ganti warna bola, tambah warna lain, bikin bola glow/neon, putar/miringkan kapsul, taruh wordmark di dalam ikon, atau pakai efek kaca di mark kecil (<32 dp).
Catatan teknis
Android adaptive icon: latar = layer background, kapsul + bola = foreground (aman di zona 66%). iOS: export 1024 tanpa transparansi. Ukuran 48 dp belum dicek — dua titik kecil mungkin perlu dihapus di varian kecil.
